# Set up CONN Pilot

Use the configured `conn-pilot` MCP server and complete browser OAuth under the
researcher's own identity. Never request passwords, one-time codes, access
tokens, refresh tokens, client secrets, private host addresses, or local dataset
paths in chat.

After authentication, inspect identity-scoped capabilities, supported analysis
families, visible datasets, evidence corpus version, and worker health. Keep this
initial verification read-only. Do not create, modify, submit, retry, or accept a
project or subject during setup.

Explain authentication, authorization, validation, worker availability, and
scientific uncertainty as separate states. On success, suggest the experiment
design workflow rather than assuming that a dataset or pipeline is suitable.
